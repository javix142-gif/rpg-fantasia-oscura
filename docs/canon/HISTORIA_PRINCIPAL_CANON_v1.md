# RPG FANTASÍA OSCURA — HISTORIA PRINCIPAL COMPLETA
## Documento canónico para futura implementación

**Versión:** 1.0  
**Estado:** CANON DE DISEÑO  
**Alcance:** campaña principal completa, desde el ataque a Liria hasta Cyrion y los distintos desenlaces.

---

# 1. Estructura general

### Duración objetivo

| Tipo de partida | Duración |
|---|---:|
| Sólo historia crítica | 5–8 h |
| Partida normal | 8–12 h |
| Exploratoria | 10–15 h |
| Ver gran parte del contenido | Requiere varias partidas |

La campaña se estructura como:

**Prólogo + 13 capítulos + epílogo variable**

Cinco actos:

1. El mundo conocido.
2. Los cuatro herederos.
3. La quinta pieza.
4. La verdad de Ilyrion.
5. La decisión.

La historia debe ser flexible, pero no caótica:

> inicio fijo → Cyrion como hub → cuatro crisis regionales parcialmente flexibles → regreso a Cyrion → revelación de Ilyrion → decisión final.

---

# 2. Regla narrativa

La historia mundial avanza incluso si el protagonista:

- explora;
- comercia;
- ignora misiones;
- busca poder;
- se une a facciones;
- intenta vivir normalmente.

No existe un reloj invisible castigando al jugador.

El mundo avanza mediante:

- viajes importantes;
- descansos;
- capítulos;
- misiones;
- decisiones;
- acontecimientos históricos.

La inacción también constituye una decisión.

---

# 3. Sistema de decisiones

No existe una barra Bien/Mal.

La historia registra:

- reputación;
- fama;
- alianzas;
- corrupción;
- conocimiento;
- acciones públicas;
- acciones privadas;
- personas salvadas;
- traiciones;
- economía;
- estado de cada reino.

Las consecuencias pueden aparecer horas después.

---

# 6. Primeros minutos

El juego no comienza con guerra.

Comienza con:

- caminar;
- hablar con vecinos;
- ayudar;
- comprar;
- practicar combate;
- conocer familia/amigos;
- elegir clase.

Esto funciona como tutorial y, sobre todo, construye apego emocional.

- inventario.
