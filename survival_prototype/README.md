# Ceniza Salvaje — prototipo survival 2D procedural

Prototipo Android autocontenido en Godot 4.7.2, 640×360 landscape y renderer Compatibility.

## Incluye

- mundo determinista por seed con 3 biomas: bosque, pradera y cenizal;
- recolección de madera, piedra, fibra, comida y mineral;
- fabricación de hacha, pico y vendas;
- construcción con snap de fogata, muro y cofre funcional;
- tres enemigos: lobo, acechador y saqueador;
- vida, hambre y resistencia;
- ciclo día/noche y clima;
- controles táctiles integrados y teclado para pruebas;
- guardado local de seed, posición, inventario, recursos retirados y construcciones.

## Controles táctiles

- joystick izquierdo: mover;
- A: atacar;
- E: recolectar/interactuar;
- C: fabricar receta seleccionada;
- B: construir elemento seleccionado;
- botones `REC` y `CON` arriba a la derecha: cambiar receta/construcción.

## Teclado

WASD/flechas mover, E interactuar, Espacio atacar, C fabricar, B construir, Q/R cambiar selección, F comer, H usar venda, N nueva seed.

## Android

Preset `Android`, package `org.cenizasalvaje.prototype`, ARM64 solamente, APK debug firmado para prueba directa.
